# Design Tokens

VivUI's tokens are the *only* place colors, sizes, and motion values are defined.
Components reference tokens, not raw values — that's what makes the entire system
themeable at runtime.

## Architecture

```
src/styles/globals.css        ← CSS variables (the runtime source of truth)
src/theme/tokens/*.ts         ← typed JS mirrors (for token tables, charts, docs)
tailwind.preset.cjs           ← maps Tailwind utilities → variables
```

## Color tokens

All colors are stored as `H S% L%` triplets so Tailwind's `<alpha-value>` syntax
works (`bg-brand/40` etc.).

## Motion

| Token | Default value | Use |
| --- | --- | --- |
| `--viv-duration-instant` | 80ms | tooltips, micro press feedback |
| `--viv-duration-fast`    | 140ms | hover states, color transitions |
| `--viv-duration`         | 220ms | entrances, popovers |
| `--viv-duration-slow`    | 360ms | dialogs, sheets |
| `--viv-duration-slower`  | 600ms | hero/intro animations |
| `--viv-ease`             | `cubic-bezier(.22,1,.36,1)` | the default expressive ease |
| `--viv-ease-spring`      | `cubic-bezier(.34,1.56,.64,1)` | playful AI feedback |
