# Theming

VivUI uses **CSS variables under `data-theme`** for theming.
This pattern (popularized by shadcn/ui and Radix Themes) is:

- ✅ SSR-safe (no JS required to apply a theme)
- ✅ Per-subtree (any element can host `data-theme`)
- ✅ Animatable (variables transition smoothly)
- ✅ Bundler-friendly (no runtime CSS-in-JS overhead)

## How it works

1. `styles/globals.css` defines the variables under `:root` (light) and
   `[data-theme="dark"]` (dark).
2. `<ThemeProvider />` writes `data-theme` to `<html>` based on user preference.
3. `<VivUIScript />` runs *before hydration* in your `<head>` so the page
   never flashes the wrong theme.

## Provider

```tsx
import { ThemeProvider, VivUIScript } from "@vivui/react";

export default function RootLayout({ children }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <head><VivUIScript /></head>
      <body>
        <ThemeProvider defaultTheme="system">{children}</ThemeProvider>
      </body>
    </html>
  );
}
```

## Hook

```tsx
import { useTheme } from "@vivui/react";

function ThemeSwitch() {
  const { resolvedTheme, toggleTheme } = useTheme();
  return (
    <button onClick={toggleTheme}>
      {resolvedTheme === "dark" ? "☀️ Light" : "🌙 Dark"}
    </button>
  );
}
```

## Custom themes

You can author additional themes by defining a new `[data-theme="..."]` block:

```css
[data-theme="cyber"] {
  --viv-brand: 180 100% 60%;
  --viv-bg: 240 30% 4%;
  --viv-surface: 240 25% 8%;
  /* ...override only what changes */
}
```

Then apply with `<div data-theme="cyber">…</div>` — the entire subtree adopts that theme,
which is great for A/B testing or branded sub-experiences.
